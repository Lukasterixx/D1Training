Scripted pick

Finds a cup with YOLO, places it with depth and forward kinematics, and drives the arm through the same sequence the simulated pick runs. The gripper is not commanded: this is a reach, a descent and a lift, not a grasp. STOP interrupts it and leaves the arm holding.
Nothing here asks where the table is. Every pose is placed from the arm's own mount and the cup is measured by the camera, so there is no height to set and none to get wrong.

Gripper

Servo 6 on the protocol's own scale, which runs −19.8 (pads touching) to +50.2 (widest) (F-063). More units is a wider jaw. The closing half is negative, which is why the vendor's advertised 0–65 could never shut it — it floored every closing command two thirds of the way open. What a unit is in millimetres is still unmeasured: command a value, put a ruler across the fingers, and that pair of numbers is the calibration this arm is missing.

Wrist mount where the camera sits

Move the RealSense against the wrist until it sits where the bracket holds it, then SAVE. The simulator and this controller can both be started with the saved file, so they agree on the extrinsics. This is an alignment by eye, not a hand-eye calibration — the file it writes says so, and so should anything that cites it.
